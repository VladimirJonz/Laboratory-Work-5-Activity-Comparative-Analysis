B. Evaluation Metrics

4. Why is accuracy not enough to evaluate a model?
Ans: However, accuracy is not sufficient for measuring the effectiveness of models since it is deceptive, particularly when there is an imbalance in the data. Suppose one category contains 900 pictures while another has only 100 images. In that case, the algorithm will still be able to reach 90% accuracy by predicting the category with a greater number of images. However, it does not learn anything from the data. That is why there are other methods such as Precision, Recall, and F1-score. They provide a more thorough understanding of the model's performance per category. Precision informs about how accurate the model's prediction was, Recall indicates how many true positives did the model correctly predict, and F1 score combines both measures into one. All these metrics, including Confusion Matrix, ROC Curve, and AUC Score, allow assessing whether the model learns something or simply favors certain categories.

9. Which model had the highest AUC score?
Ans: EfficientNetB0 mostly got the highest AUC score out of the three pre-trained models since the Area Under the Curve (AUC) metric evaluates the capacity of the model to discriminate between classes by considering all classification thresholds, and thus, the architecture of EfficientNetB0 and the efficiency of its feature extraction process enabled it to provide the most accurate probability estimation. High AUC score means that EfficientNetB0 has the best trade-off between true positives and false positives rates, which allows it to detect positive cases more reliably. In contrast, MobileNetV2 usually provided moderate AUC scores since despite the confident classification performed by it, the lightweight nature of MobileNetV2 led to slightly lower discriminative ability, whereas VGG16 demonstrated the worst AUC score** due to the outdatedness of its architecture and difficulties with learning the custom data set. Thus, the closer the AUC score to 1.0 (the best case scenario – EfficientNetB0), the better classifier it is; if the value is closer to 0.5 (like in the case of VGG16), it simply means that the classifier is barely better than random guessing.

10. What does AUC tell us about model performance?
Ans:The Area Under the Curve (AUC) allows to understand how effectively a machine learning model ranks and discriminates among different classes when varying the classification thresholds, which makes it a global indicator of performance. The value AUC = 1 corresponds to perfectly classified data, which means that the classifier makes absolutely accurate predictions, while AUC = 0.5 is equal to flipping a coin — such model performs no better than random guessing. One of the strengths of using AUC lies in its robustness against class imbalance: AUC does not depend on class proportions and assesses the performance of a model in separating classes for every possible classification threshold, which provides an unbiased estimation of classifier's performance. High AUC value (for instance, greater than 0.9) indicates high confidence of a machine learning algorithm and reliability of its predictions, while low AUC value (less than 0.6) indicates weak ability of a classifier to discriminate classes and provide reliable probability estimation. To sum up, AUC allows to get insight into the discriminative ability of the model, giving us the answer whether the algorithm actually learns patterns or guesses correctly.
